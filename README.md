# Huellitas - Taller #1

Esta es una aplicación web llamada **Huellitas** que consume la
**Dog CEO API** para buscar imágenes de perros filtrando por raza. El
usuario escribe el nombre de una raza (ej: labrador, husky,
poodle) y la aplicación muestra un listado de fotos de esa raza.

## Cómo ejecutarlo

Para ejecutar el proyecto solo se necesita un navegador web y seguir los siguientes pasos:

1. Clonar el repositorio.
2. Abrir el archivo index.html en un navegador.
3. Escribir el nombre de una raza en el campo de búsqueda y presionar buscar.
